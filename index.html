  3. Deploy เวอร์ชันใหม่ · Deploy → Manage deployments → ✏️ → Version: New version → Deploy · ใช้ URL เดิมหรือลิงก์หน้าห่อ GitHub Pages ที่มีอยู่ (ไม่ต้องเปลี่ยน)
